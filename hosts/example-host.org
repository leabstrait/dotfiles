* System Overview
This file manages the system-level configuration, package installation, and setup commands for my main home desktop.

* Package Management
To install or update the core packages for this system, place your cursor inside the block below and press =C-c C-c=.

** System Packages (Arch/Pacman Example)
#+BEGIN_SRC shell :dir /sudo::
  echo "Updating system repositories..."
  pacman -Syu --noconfirm

  echo "Installing required applications..."
  pacman -S --needed --noconfirm \
    ripgrep \
    fd \
    git \
#+END_SRC

** User-space Packages
No sudo required for these, so we don't pass the sudo argument.
#+BEGIN_SRC shell
  echo "Installing user applications..."
  pacman -S firefox
#+END_SRC
