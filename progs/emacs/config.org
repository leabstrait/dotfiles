* INTRODUCTION: THE EMACS KEYBIND PHILOSOPHY & STRUCTURE

Unlike modern text editors that rely on a static set of shortcuts (like ~Ctrl+C~ for copy, ~Ctrl+V~ for paste), Emacs treats the keyboard as a fluent, modal command interface. Every keypress or combination runs a discrete Lisp function under the hood.

** The Core Input Philosophy

The Emacs keyboard philosophy is designed around three core principles:

1. *Touch-Typist Efficiency*: Standard shortcuts avoid the function keys (~F1~-~F12~), arrow keys, or mouse inputs. Keeping your hands anchored to the home row minimizes physical strain during long development sessions.

2. *Infinite Extensibility*: Because Emacs has thousands of built-in commands, it uses chords (pressing multiple keys sequentially) to prevent running out of keyboard real estate.

3. *Contextual Adaptability*: The meaning of your keys changes depending on the file type you are editing, creating a contextual interface that adapts to your workflow.

** Anatomy of a Keybind: Prefixes and Chords

Emacs groups commands logically using *Prefix Keys*. A prefix key acts as a gateway to a specific family of commands. Once you press a prefix, Emacs waits for the next key in the chord.
* ~C-x~ *(Control + x)*: The *Global System Prefix*. Used for fundamental editor operations like handling buffers, opening files, and quitting.

  * ~C-x C-s~: Save the current file.
  * ~C-x C-b~: List open buffers.

* ~C-c~ *(Control + c)*: The *User / Mode Prefix*. Reserved specifically for user customizations and major-mode specific commands.

  * ~C-c l~: Bound to our Language Server Protocol (~lsp-mode~) map.

* ~M-x~ *(Alt + x)*: The *Command HUD*. This opens a minibuffer where you can type out and execute any Emacs function by its plain-text name.

** The Keymap Hierarchy

When you press a key, Emacs filters your input through a strict map hierarchy. The first map that contains a definition for your key combination wins:

1. *Emulation Maps*: Used by packages like ~evil-mode~ to completely hijack inputs.
2. *Minor Mode Maps*: Modular, opt-in features that span across major modes (e.g., ~yafolding-mode~ or ~lsp-mode~). These override major modes to ensure their utilities remain globally accessible.
3. *Major Mode Maps*: File-type specific configurations (e.g., ~python-mode~, ~js-mode~). Pressing ~TAB~ in Python indents by 4 spaces, while in ~web-mode~ it might indent by 2.
4. *Global Map*: The catch-all baseline map. If a key isn't claimed by a major or minor mode, Emacs looks here.

** Fonts

   #+BEGIN_SRC emacs-lisp
(defun my/set-font-size-by-dpi (&optional frame)
  "Dynamically set default font height normalized across macOS, Linux, and external displays."
  (let* ((target-frame (or frame (selected-frame))))
    (when (display-graphic-p target-frame)
      (let* ((attrs (frame-monitor-attributes target-frame))
             (geom  (cdr (assq 'geometry attrs)))
             (mm    (cdr (assq 'mm-size attrs)))
             (px-w  (nth 2 geom))
             (mm-w  (car mm))
             ;; Frame scaling factor (2.0 on Mac Retina, 1.0 on standard Linux)
             (scale (if (fboundp 'frame-scale-factor)
                        (frame-scale-factor target-frame)
                      1.0))
             ;; Raw DPI based on reported display geometry
             (raw-dpi (and px-w mm-w (> mm-w 0) (* (/ (float px-w) mm-w) 25.4)))
             ;; Normalized logical DPI
             (effective-dpi (and raw-dpi (/ raw-dpi scale)))
             ;; Corrected Tiering:
             ;; 1. HiDPI scaling active (e.g. macOS Retina, scale >= 2.0) -> 140
             ;; 2. High physical DPI on standard scale (e.g. Linux 1080p laptop, ~140 DPI) -> 110
             ;; 3. Low DPI / Large external monitors (< 110 DPI) -> 100
             (height (cond
                       ((>= scale 2.0) 140)
                       ((and effective-dpi (> effective-dpi 110)) 100)
                       (t 90))))

        ;; Apply font settings to the target frame
        (set-face-attribute 'default target-frame
                            :font "FiraCode Nerd Font"
                            :height height
                            :weight 'normal) ;; 'normal fixes excess boldness on macOS
        (message "[font] Frame %s | Scale: %.1f | Effective DPI: %s | Height: %d"
                 target-frame
                 scale
                 (if effective-dpi (format "%.1f" effective-dpi) "N/A")
                 height)))))

;; Initialize on startup
(add-hook 'window-setup-hook #'my/set-font-size-by-dpi)

;; Handle newly spawned client frames (daemon mode or multi-window)
(add-hook 'after-make-frame-functions #'my/set-font-size-by-dpi)

;; Dynamically adjust when dragging frames across external monitors
(add-hook 'move-frame-functions #'my/set-font-size-by-dpi)

     (setq-default line-spacing 0.12)

  ;; Enable the "www" ligature in every possible major mode

  ;; Enable all Cascadia and Fira Code ligatures in programming modes
  (ligature-set-ligatures 'prog-mode
                        '(;; == === ==== => =| =>>=>=|=>==>> ==< =/=//=// =~
                          ;; =:= =!=
                          ("=" (rx (+ (or ">" "<" "|" "/" "~" ":" "!" "="))))
                          ;; ;; ;;;
                          (";" (rx (+ ";")))
                          ;; && &&&
                          ("&" (rx (+ "&")))
                          ;; !! !!! !. !: !!. != !== !~
                          ("!" (rx (+ (or "=" "!" "\." ":" "~"))))
                          ;; ?? ??? ?:  ?=  ?.
                          ("?" (rx (or ":" "=" "\." (+ "?"))))
                          ;; %% %%%
                          ("%" (rx (+ "%")))
                          ;; |> ||> |||> ||||> |] |} || ||| |-> ||-||
                          ;; |->>-||-<<-| |- |== ||=||
                          ;; |==>>==<<==<=>==//==/=!==:===>
                          ("|" (rx (+ (or ">" "<" "|" "/" ":" "!" "}" "\]"
                                          "-" "=" ))))
                          ;; \\ \\\ \/
                          ("\\" (rx (or "/" (+ "\\"))))
                          ;; ++ +++ ++++ +>
                          ("+" (rx (or ">" (+ "+"))))
                          ;; :: ::: :::: :> :< := :// ::=
                          (":" (rx (or ">" "<" "=" "//" ":=" (+ ":"))))
                          ;; // /// //// /\ /* /> /===:===!=//===>>==>==/
                          ("/" (rx (+ (or ">"  "<" "|" "/" "\\" "\*" ":" "!"
                                          "="))))
                          ;; .. ... .... .= .- .? ..= ..<
                          ("\." (rx (or "=" "-" "\?" "\.=" "\.<" (+ "\."))))
                          ;; -- --- ---- -~ -> ->> -| -|->-->>->--<<-|
                          ("-" (rx (+ (or ">" "<" "|" "~" "-"))))
                          ;; *> */ *)  ** *** ****
                          ("*" (rx (or ">" "/" ")" (+ "*"))))
                          ;; www wwww
                          ("w" (rx (+ "w")))
                          ;; <> <!-- <|> <: <~ <~> <~~ <+ <* <$ </  <+> <*>
                          ;; <$> </> <|  <||  <||| <|||| <- <-| <-<<-|-> <->>
                          ;; <<-> <= <=> <<==<<==>=|=>==/==//=!==:=>
                          ;; << <<< <<<<
                          ("<" (rx (+ (or "\+" "\*" "\$" "<" ">" ":" "~"  "!"
                                          "-"  "/" "|" "="))))
                          ;; >: >- >>- >--|-> >>-|-> >= >== >>== >=|=:=>>
                          ;; >> >>> >>>>
                          (">" (rx (+ (or ">" "<" "|" "/" ":" "=" "-"))))
                          ;; #: #= #! #( #? #[ #{ #_ #_( ## ### #####
                          ("#" (rx (or ":" "=" "!" "(" "\?" "\[" "{" "_(" "_"
                                       (+ "#"))))
                          ;; ~~ ~~~ ~=  ~-  ~@ ~> ~~>
                          ("~" (rx (or ">" "=" "-" "@" "~>" (+ "~"))))
                          ;; __ ___ ____ _|_ __|____|_
                          ("_" (rx (+ (or "_" "|"))))
                          ;; Fira code: 0xFF 0x12
                          ("0" (rx (and "x" (+ (in "A-F" "a-f" "0-9")))))
                          ;; Fira code:
                          "Fl"  "Tl"  "fi"  "fj"  "fl"  "ft"
                          ;; The few not covered by the regexps.
                          "{|"  "[|"  "]#"  "(*"  "}#"  "$>"  "^="))
